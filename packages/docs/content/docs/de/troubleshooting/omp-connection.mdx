# OMP-Verbindung

Wenn OMPChamber lädt, aber nie über „OMP is restarting“ hinauskommt, oder der Chat nicht antwortet, ist der Server, mit dem es spricht, nicht erreichbar. Gehen Sie diese Punkte durch.

## Es hängt bei „OMP is restarting“

- geben Sie ihm direkt nach dem Start einen Moment — dieser Zustand ist normal, während der Server hochfährt
- prüfen Sie mit `ompchamber status`, ob der Server noch läuft
- starten Sie ihn mit `ompchamber restart` neu
- sehen Sie sich mit `ompchamber logs` die Startdetails an

## Es schlägt immer noch fehl

- bestätigen Sie, dass Node.js Version `20` oder neuer ist
- installieren Sie die neueste CLI neu
- öffnen Sie `http://localhost:3000` direkt, bevor Sie einen Tunnel- oder Remote-Link testen
