# Agent-Steuerungswerkzeug

Verwende das Agentenwerkzeug `ompchamber`, um Arbeit in der App direkt aus dem Chat zu verwalten. Es ist standardmäßig aktiviert, wenn OMPChamber seinen eigenen lokalen OMPChamber-Server ausführt; du musst kein separates Werkzeug installieren und keinen Shell-Befehl ausführen.

## Was du anfragen kannst

Sprich einfach in natürlicher Sprache mit dem Agenten. Zum Beispiel:

- "Erstelle in diesem Projekt eine neue OMPChamber-Sitzung, verwende das Modell `openai/gpt-5.6-sol` und sende ihr diese Aufforderung: überprüfe den Authentifizierungsfluss."
- "Erstelle für diese Aufgabe eine neue OMPChamber-Sitzung in einem separaten Worktree und bitte sie, Tests für den Login-Fluss hinzuzufügen."
- "Verwende OMPChamber, um meine 10 neuesten Sitzungen aufzulisten und ihren aktuellen Status anzuzeigen."
- "Erstelle eine geplante OMPChamber-Aufgabe mit dem Namen Weekday review, die diese Aufforderung werktags um 09:00 sendet: review changes since the last run."
- "Führe die geplante OMPChamber-Aufgabe mit dem Namen Weekday review jetzt aus."
- "Prüfe die OMPChamber-Sitzung mit dem Namen Authentication review und zeige mir die neueste Antwort des Assistenten."

Das Werkzeug kann Projekte und Modelleinstellungen auflisten, Sitzungen erstellen und weiterführen, eine Sitzung forken, isolierte Worktree-Sitzungen erstellen und geplante Aufgaben verwalten. Auf diese Weise gestartete Sitzungen erscheinen in OMPChamber wie jede andere Sitzung auch, sodass du sie öffnen und die Arbeit selbst fortsetzen kannst.

## Beachten

- Neue Sitzungsaufforderungen kehren standardmäßig sofort zurück. Verfolge die Sitzung in OMPChamber oder bitte den Agenten, sie später noch einmal zu prüfen.
- Ein separater Worktree wird nur erstellt, wenn du ausdrücklich danach fragst. Nicht-committete Änderungen aus deinem aktuellen Worktree werden nicht dorthin kopiert.
- Das Werkzeug kann keine Sitzungen oder Worktrees löschen, keine Projektpfade registrieren, keine beliebigen Shell-Befehle ausführen und keine beliebigen URLs aufrufen.

## Werkzeug ein- oder ausschalten

Öffne **Einstellungen → Allgemein → OMP CLI**, ändere **Agent control tool** und wähle dann **Save + Reload**. Die Einstellung gilt, nachdem der verwaltete OMPChamber-Server neu gestartet wurde.

Das Werkzeug ist innerhalb der VS-Code-Erweiterung nicht verfügbar. Desktop- und Web-Installationen, die den verwalteten OMPChamber-Server verwenden, unterstützen es automatisch.
