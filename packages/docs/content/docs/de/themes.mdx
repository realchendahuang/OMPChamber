# Themes

OMPChamber unterstützt eingebaute Themes und benutzerdefinierte Theme-JSON-Dateien.

## Ein benutzerdefiniertes Theme hinzufügen

1. Erstelle das Themes-Verzeichnis:

```bash
mkdir -p ~/.config/ompchamber/themes
```

2. Füge deine JSON-Datei in dieses Verzeichnis ein (zum Beispiel `my-theme.json`).
3. Öffne OMPChamber und gehe dann zu **Einstellungen -> Theme -> Themes neu laden**.
4. Wähle dein Theme im Dropdown aus. Es wird sofort angewendet.

## Speicherort der Themes

- macOS/Linux: `~/.config/ompchamber/themes/`
