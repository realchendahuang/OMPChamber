# Conexión de OMP

Si OMPChamber carga pero nunca pasa de "OMP is restarting", o el chat no responde, el servidor con el que se comunica no es accesible. Repasa estos pasos.

## Se queda atascado en "OMP is restarting"

- dale un momento justo después de iniciar: este estado es normal mientras el servidor arranca
- comprueba si el servidor está vivo con `ompchamber status`
- reinícialo con `ompchamber restart`
- ve los detalles de arranque con `ompchamber logs`

## Sigue fallando

- confirma que Node.js sea la versión `20` o más reciente
- reinstala la última CLI
- abre `http://localhost:3000` directamente antes de probar cualquier túnel o enlace remoto
