# Instalación

Hay tres formas de ejecutar OMPChamber:

- app de escritorio para macOS
- app web alojada por la CLI, que puedes instalar como una app de teléfono (una PWA)
- extensión para VS Code

## Requisito previo

Instala [OMP](https://github.com/can1357/oh-my-pi) primero: OMPChamber se ejecuta sobre él.

## Web + PWA

```bash
curl -fsSL https://raw.githubusercontent.com/realchendahuang/OMPChamber/main/scripts/install.sh | bash
ompchamber --ui-password be-creative-here
```

Abre la URL que imprime la CLI (normalmente `http://localhost:3000`). Deberías ver la lista de sesiones de OMPChamber. Para tenerlo a mano, usa la opción "Instalar" de tu navegador en la barra de direcciones para añadirlo como una app.

## Escritorio

Descarga la última compilación de escritorio desde la página de releases de GitHub o la página de descargas de OMPChamber. Ábrela e inicia sesión con tu flujo de trabajo habitual de OMP.

## VS Code

Instálala desde el VS Code Marketplace e inicia sesión con tu flujo de trabajo habitual de OMP. La vista de OMPChamber se abre entonces en la barra lateral.
