# Variables de entorno

OMPChamber lee estas variables al arrancar. Para servicios de inicio, `ompchamber startup enable` guarda por defecto una copia del entorno actual, así que vuelve a ejecutarlo después de cambiar variables que quieras usar en el servicio.

## Servidor OMPChamber

### `OMPCHAMBER_HOST`

Dirección donde escucha el servidor web de OMPChamber. Usa `0.0.0.0` para permitir acceso desde otras máquinas.

### `OMPCHAMBER_UI_PASSWORD`

Contraseña para la interfaz del navegador. Úsala cuando no te limites a localhost, o cuando uses túneles o un proxy inverso.

### `OMPCHAMBER_API_ONLY`

Inicia OMPChamber en modo headless cuando vale `true` o `1`. Las rutas API siguen disponibles para clientes de escritorio y móviles, pero no se sirve la UI del navegador.

### `OMPCHAMBER_DATA_DIR`

Cambia el directorio de datos de OMPChamber. Por defecto es `~/.config/ompchamber`.

### `OMPCHAMBER_COMPRESS_API`

Controla la compresión de respuestas de la API. `true` o `1` la activa; `false` o `0` la desactiva.

### `OMPCHAMBER_SKIP_API_COMPRESSION`

Desactiva la compresión de respuestas de la API si vale `true` o `1`. Tiene prioridad sobre `OMPCHAMBER_COMPRESS_API`.

### `OMPCHAMBER_VERBOSE_REQUEST_LOGS`

Activa logs HTTP detallados si vale `true` o `1`.

### `OMPCHAMBER_UPDATE_API_URL`

Cambia el endpoint de comprobación de actualizaciones. La mayoría de usuarios no debería tocarlo.

### `OMPCHAMBER_PACKAGE_MANAGER`

Fuerza el gestor de paquetes usado para actualizar cuando la detección automática se equivoca.

## Servidor OMP

### `OPENCODE_PORT`

Define el puerto del servidor OMP. Con OMP gestionado pide ese puerto.

### `OMP_BINARY`

Ruta al ejecutable `omp` que debe usar OMPChamber.

### `OPENCODE_BINARY`

Alias obsoleto de `OMP_BINARY`, aún se admite como fallback.

### `OPENCODE_CONFIG`

Ruta a un archivo de configuración concreto de OMP.

### `OPENCODE_CONFIG_DIR`

Ruta al directorio de configuración de OMP para agents, skills, snippets y descubrimiento de config.

### `OPENCODE_DATA_DIR`

Directorio de datos personalizado para el servidor OMP gestionado.

### `OPENCODE_WSL_DISTRO`

Elige la distro WSL usada para la integración con OMP en Windows.

### `OMPCHAMBER_OPENCODE_WSL_DISTRO`

Alias específico de OMPChamber para elegir la distro WSL. `OPENCODE_WSL_DISTRO` tiene prioridad si ambas están definidas.

### `OPENCODE_JWT_SECRET`

Secreto para firmar tokens de autenticación de la UI. En servicios persistentes, usa un valor largo y aleatorio.

## Terminal y Git

### `OMPCHAMBER_TERMINAL_SHELL`

Ejecutable de shell para las sesiones de terminal en OMPChamber.

### `OMPCHAMBER_GIT_BINARY`

Ejecutable de Git usado por las funciones Git de OMPChamber.

### `GIT_BINARY`

Override alternativo para el ejecutable de Git. Para ajustes específicos de OMPChamber, prefiere `OMPCHAMBER_GIT_BINARY`.

### `OMPCHAMBER_GIT_READ_CACHE_TTL_MS`

TTL, en milisegundos, para lecturas de archivos con cache respaldadas por Git. Usa `0` para desactivar la cache al depurar.

## Voz y túneles

### `OPENAI_API_KEY`

API key para funciones de voz de OMPChamber que llaman a servicios compatibles con OpenAI.

### `OMPCHAMBER_ALLOW_REMOTE_OPENAI_COMPAT_URLS`

Permite base URLs remotas compatibles con OpenAI para funciones de voz cuando vale `true` o `1`.

### `NGROK_AUTHTOKEN`

Token de autenticación de ngrok usado por los comandos de túnel de OMPChamber. También puedes configurarlo con `ngrok config add-authtoken <token>`.

## Ayudas de runtime

### `BUN_BINARY`

Ejecutable de Bun que OMPChamber debe usar al iniciar procesos daemon.

### `BUN_INSTALL`

Raíz de instalación de Bun. OMPChamber la usa para encontrar `bin/bun` al iniciar daemons y actualizar.

### `VITE_OPENCODE_URL`

API base URL de build-time para la web app construida con Vite. La mayoría de usuarios no debería usarla en CLI o desktop normales.
