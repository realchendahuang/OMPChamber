# Updates

How you update OMPChamber depends on how you installed it. In every case you can check your current version at **Settings → OMPChamber → About**.

## Desktop app

The desktop app checks for updates against GitHub releases. When one is available, OMPChamber tells you, downloads it when you choose, and installs it on the next restart. You're always in control — nothing installs without your say-so.

## Web / CLI

If you installed the CLI, update it from **About** with the check and update buttons, or from the terminal:

```bash
ompchamber update
```

OMPChamber detects how it was installed (npm, pnpm, yarn, or bun) and runs the right update for you.

## The OMP server

OMPChamber and OMP update separately. When a new OMP version is available, OMPChamber offers to update it and restarts the server afterward. See [OMPChamber Server](/omp-server/) for how that server is managed.
