# Installation

Il existe trois façons d’utiliser OMPChamber :

- l’application desktop pour macOS
- l’application web servie par la CLI, que vous pouvez installer comme une application de téléphone (une PWA)
- l’extension VS Code

## Prérequis

Installez d’abord [OMP](https://github.com/can1357/oh-my-pi) — OMPChamber fonctionne par-dessus.

## Web + PWA

```bash
curl -fsSL https://raw.githubusercontent.com/realchendahuang/OMPChamber/main/scripts/install.sh | bash
ompchamber --ui-password be-creative-here
```

Ouvrez l’URL affichée par la CLI (souvent `http://localhost:3000`). Vous devriez voir la liste des sessions OMPChamber. Pour la garder à portée de main, utilisez l’option « Installer » de votre navigateur dans la barre d’adresse pour l’ajouter comme application.

## Desktop

Téléchargez la dernière version desktop depuis la page des releases GitHub ou la page de téléchargement OMPChamber. Ouvrez-la et connectez-la à votre workflow OMP habituel.

## VS Code

Installez l’extension depuis le VS Code Marketplace et connectez-la à votre workflow OMP habituel. La vue OMPChamber s’ouvre ensuite dans la barre latérale.
