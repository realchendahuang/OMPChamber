# Connexion à OMP

Si OMPChamber se charge mais reste bloqué sur « OMP redémarre », ou si le chat ne répond pas, le serveur auquel il parle n’est pas joignable. Suivez ces vérifications.

## Il reste bloqué sur « OMP redémarre »

- laissez-lui un moment juste après le lancement — cet état est normal pendant le démarrage du serveur
- vérifiez si le serveur est vivant avec `ompchamber status`
- redémarrez-le avec `ompchamber restart`
- consultez les détails de démarrage avec `ompchamber logs`

## Toujours en échec

- confirmez que Node.js est en version `20` ou plus récente
- réinstallez la dernière CLI
- ouvrez `http://localhost:3000` directement avant de tester un tunnel ou lien distant
