# OMP 연결

OMPChamber가 로드되지만 "OMP is restarting"에서 넘어가지 못하거나 채팅이 응답하지 않는다면, 통신하는 서버에 접근할 수 없는 상태입니다. 다음을 차례로 확인하세요.

## "OMP is restarting"에서 멈춰 있음

- 실행 직후에는 잠시 기다리세요. 서버가 시작되는 동안에는 정상적인 상태입니다
- `ompchamber status`로 서버가 살아 있는지 확인합니다
- `ompchamber restart`로 재시작합니다
- `ompchamber logs`로 시작 세부 정보를 봅니다

## 여전히 실패함

- Node.js 버전이 `20` 이상인지 확인합니다
- 최신 CLI를 다시 설치합니다
- 터널이나 원격 링크를 테스트하기 전에 `http://localhost:3000`을 직접 엽니다
