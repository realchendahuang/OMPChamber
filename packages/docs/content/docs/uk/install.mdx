# Встановлення

Є три способи запустити OMPChamber:

- десктоп-застосунок для macOS
- вебзастосунок на базі CLI, який можна встановити як застосунок на телефоні (PWA)
- розширення для VS Code

## Передумова

Спершу встановіть [OMP](https://github.com/can1357/oh-my-pi) — OMPChamber працює поверх нього.

## Веб + PWA

```bash
curl -fsSL https://raw.githubusercontent.com/realchendahuang/OMPChamber/main/scripts/install.sh | bash
ompchamber --ui-password be-creative-here
```

Відкрийте URL, який вивів CLI (зазвичай `http://localhost:3000`). Ви маєте побачити список сесій OMPChamber. Щоб він був під рукою, скористайтеся опцією «Install» в адресному рядку браузера й додайте його як застосунок.

## Десктоп

Завантажте найновішу десктопну збірку зі сторінки релізів на GitHub або зі сторінки завантаження OMPChamber. Відкрийте її та увійдіть у свій звичний робочий процес OMP.

## VS Code

Встановіть із VS Code Marketplace і увійдіть у свій звичний робочий процес OMP. Після цього вікно OMPChamber відкриється на бічній панелі.
