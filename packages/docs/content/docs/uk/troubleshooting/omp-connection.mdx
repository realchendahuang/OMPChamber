# Підключення до OMP

Якщо OMPChamber завантажується, але ніяк не виходить за межі стану «OMP перезапускається», або чат не відповідає, сервер, із яким він спілкується, недоступний. Пройдіться по цьому.

## Він застряг на «OMP перезапускається»

- дайте йому хвилину одразу після запуску — цей стан нормальний, поки сервер стартує
- перевірте, чи сервер живий, командою `ompchamber status`
- перезапустіть його командою `ompchamber restart`
- перегляньте деталі запуску командою `ompchamber logs`

## Ви підключаєтеся до власного сервера

Якщо ви налаштували OMPChamber на використання наявного сервера, ще раз перевірте налаштування з [OMPChamber Server](/uk/omp-server/):

- `OPENCODE_HOST` має містити порт, без шляху — наприклад, `http://localhost:4096`
- задайте `OPENCODE_SKIP_START=true`, щоб OMPChamber не запускав ще й свій
- якщо адреса недійсна, OMPChamber ігнорує її й натомість запускає власний сервер — шукайте попередження `[config]` у журналах

## Усе ще не працює

- переконайтеся, що версія Node.js — `20` або новіша
- перевстановіть найновіший CLI
- відкрийте `http://localhost:3000` напряму, перш ніж тестувати будь-який тунель чи віддалене посилання
