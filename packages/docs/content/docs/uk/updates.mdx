# Оновлення

Те, як ви оновлюєте OMPChamber, залежить від того, як ви його встановили. У будь-якому разі ви можете перевірити свою поточну версію в **Settings → OMPChamber → About**.

## Десктопний застосунок

Десктопний застосунок перевіряє наявність оновлень у релізах GitHub. Коли воно доступне, OMPChamber повідомляє вам, завантажує його, коли ви оберете, і встановлює при наступному перезапуску. Ви завжди керуєте процесом — нічого не встановлюється без вашого схвалення.

## Веб / CLI

Якщо ви встановили CLI, оновіть його з **About** кнопками перевірки та оновлення або з терміналу:

```bash
ompchamber update
```

OMPChamber визначає, як його було встановлено (npm, pnpm, yarn чи bun), і запускає правильне оновлення за вас.

## Сервер OMP

OMPChamber та OMP оновлюються окремо. Коли доступна нова версія OMP, OMPChamber пропонує оновити її й перезапускає сервер після цього. Див. [OMPChamber Server](/uk/omp-server/) про те, як цим сервером керують.
