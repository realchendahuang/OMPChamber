# OMP 连接

如果 OMPChamber 加载了但始终无法越过 “OMP is restarting”，或者聊天没有响应，那就是它所通信的服务器无法访问。请逐项排查。

## 卡在 “OMP is restarting”

- 启动后稍等片刻 — 服务器启动期间出现此状态是正常的
- 用 `ompchamber status` 检查服务器是否存活
- 用 `ompchamber restart` 重启它
- 用 `ompchamber logs` 查看启动详情

## 仍然失败

- 确认 Node.js 是 `20` 或更新版本
- 重新安装最新的 CLI
- 在测试任何隧道或远程链接之前，先直接打开 `http://localhost:3000`
