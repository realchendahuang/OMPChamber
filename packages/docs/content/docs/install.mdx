# Install

There are three ways to run OMPChamber:

- desktop app for macOS
- web app hosted by the CLI, which you can install like a phone app (a PWA)
- VS Code extension

## Prerequisite

Install [OMP](https://github.com/can1357/oh-my-pi) first — OMPChamber runs on top of it.

## Web + PWA

```bash
curl -fsSL https://raw.githubusercontent.com/realchendahuang/OMPChamber/main/scripts/install.sh | bash
ompchamber --ui-password be-creative-here
```

Open the URL the CLI prints (usually `http://localhost:3000`). You should see the OMPChamber session list. To keep it handy, use your browser's "Install" option in the address bar to add it as an app.

## Desktop

Download the latest desktop build from the GitHub releases page or the OMPChamber download page. Open it and sign into your usual OMP workflow.

## VS Code

Install from the VS Code Marketplace and sign into your usual OMP workflow. The OMPChamber view then opens in the sidebar.
