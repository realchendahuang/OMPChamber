# Połączenie z OMP

Jeśli OMPChamber się ładuje, ale nigdy nie przechodzi poza „OMP uruchamia się ponownie”, albo czat nie odpowiada, serwer, z którym się komunikuje, jest nieosiągalny. Przejdź przez te kroki.

## Utknął na „OMP uruchamia się ponownie”

- daj mu chwilę tuż po uruchomieniu — ten stan jest normalny, gdy serwer startuje
- sprawdź, czy serwer żyje, za pomocą `ompchamber status`
- zrestartuj go za pomocą `ompchamber restart`
- zobacz szczegóły startu za pomocą `ompchamber logs`

## Nadal nie działa

- potwierdź, że Node.js jest w wersji `20` lub nowszej
- przeinstaluj najnowsze CLI
- otwórz `http://localhost:3000` bezpośrednio, zanim przetestujesz jakikolwiek tunel lub zdalny link
