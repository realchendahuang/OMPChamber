# Motywy

OMPChamber obsługuje wbudowane motywy oraz własne pliki JSON z motywami.

## Dodaj własny motyw

1. Utwórz katalog motywów:

```bash
mkdir -p ~/.config/ompchamber/themes
```

2. Dodaj swój plik JSON do tego katalogu (na przykład `my-theme.json`).
3. Otwórz OMPChamber, a następnie przejdź do **Settings -> Theme -> Reload themes**.
4. Wybierz swój motyw z listy rozwijanej. Zostanie zastosowany od razu.

## Lokalizacja motywów

- macOS/Linux: `~/.config/ompchamber/themes/`
