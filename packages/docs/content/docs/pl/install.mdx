# Instalacja

OMPChamber można uruchomić na trzy sposoby:

- aplikacja na komputer dla macOS
- aplikacja webowa hostowana przez CLI, którą możesz zainstalować jak aplikację na telefonie (jako PWA)
- rozszerzenie do VS Code

## Wymaganie wstępne

Najpierw zainstaluj [OMP](https://github.com/can1357/oh-my-pi) — OMPChamber działa na jego bazie.

## Przeglądarka + PWA

```bash
curl -fsSL https://raw.githubusercontent.com/realchendahuang/OMPChamber/main/scripts/install.sh | bash
ompchamber --ui-password be-creative-here
```

Otwórz adres URL wypisany przez CLI (zwykle `http://localhost:3000`). Powinna pojawić się lista sesji OMPChamber. Aby mieć ją zawsze pod ręką, użyj opcji „Zainstaluj” w pasku adresu przeglądarki, aby dodać ją jako aplikację.

## Komputer

Pobierz najnowszą kompilację na komputer ze strony wydań na GitHubie lub ze strony pobierania OMPChamber. Otwórz ją i zaloguj się do swojego zwykłego procesu pracy OMP.

## VS Code

Zainstaluj z VS Code Marketplace i zaloguj się do swojego zwykłego procesu pracy OMP. Widok OMPChamber otworzy się wtedy na pasku bocznym.
